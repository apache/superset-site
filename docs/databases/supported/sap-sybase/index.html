SAP Sybase

https://www.sap.com/products/technology-platform/sybase-ase.html
SAP ASE (formerly Sybase) is an enterprise relational database.
Installation
Required packages: sqlalchemy-sybasepyodbc
Connection String
sybase+pyodbc://{username}:{password}@{dsn}
ParameterDescription
usernameDatabase username
passwordDatabase password
dsnODBC Data Source Name configured for SAP ASE
Supported Features
JOINsSubqueriesDynamic SchemaCatalog SupportDynamic CatalogSSH TunnelingQuery CancellationFile UploadUser ImpersonationCost EstimationSQL Validation
Feature Score: 44/201
Time Grains
Common Time Grains:
SECONDMINUTEHOURDAYWEEKMONTHQUARTERYEAR
Extended Time Grains:
FIVE_SECONDSTHIRTY_SECONDSFIVE_MINUTESTEN_MINUTESFIFTEEN_MINUTESTHIRTY_MINUTESHALF_HOURSIX_HOURSWEEK_STARTING_SUNDAYWEEK_STARTING_MONDAYWEEK_ENDING_SATURDAYWEEK_ENDING_SUNDAYQUARTER_YEAR
Notes
Requires SAP ASE ODBC driver installed and configured as a DSN.
